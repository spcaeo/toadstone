# Code of conduct

## The standard

Be decent. Specifically:

- Assume the other person is competent and acting in good faith until you have
  real evidence otherwise.
- Criticise the code, the claim or the decision — never the person.
- "This is wrong, and here is the reproduction" is welcome, and is not rudeness.
  Contempt is rudeness, and it is not welcome however correct you are.
- No harassment, no sexualised language or imagery, no demeaning or derogatory
  comments about who someone is, no publishing anyone's private information.
- If you are wrong, say so plainly and move on. Nobody is keeping score.

This applies in issues, pull requests, commit messages, discussions and anywhere
else someone is representing the project.

## Enforcement

Report conduct problems through
[a private security advisory](https://github.com/spcaeo/toadstone/security/advisories/new)
if it involves anything you would rather not post publicly, or by opening an
issue if it does not.

Reports are read by the maintainer. What follows is proportionate: usually a
request to edit or withdraw a comment, sometimes a temporary or permanent ban
from the repository. Whoever reports something is not identified without their
agreement.

## Scope and borrowings

This is a condensed statement of the same ground the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
covers. It is deliberately short so that it gets read.
